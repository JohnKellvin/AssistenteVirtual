# Assistente — Jarvis para Android

Beta 3 do assistente de voz em Flutter para Android. Instruções completas em [LEIA-ME.md](LEIA-ME.md).

## Baixar o APK

- Builds de teste ficam na aba **Actions**, dentro do artefato `jarvis-apk`.
- A versão Beta 3 é publicada em **Releases** como pré-lançamento, com o APK anexado.
- As releases anteriores continuam no histórico do repositório.

## Compilar e publicar

Enviar alterações para `main` inicia o fluxo **Gerar APK**. Depois que a compilação passar, crie e envie a tag `v3.0.0-beta.1`:

```bash
git tag v3.0.0-beta.1
git push origin v3.0.0-beta.1
```
