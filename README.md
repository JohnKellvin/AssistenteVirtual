# AssistenteVirtual — Jarvis para Android

Beta 2.1 do assistente de voz em Flutter para Android. As instruções completas de instalação e uso estão em [LEIA-ME.md](LEIA-ME.md).

## Baixar o APK

- Builds de teste ficam na aba **Actions**, dentro do artefato `jarvis-apk`.
- A versão Beta 2.1 será publicada em **Releases** como pré-lançamento, com o APK anexado.
- A release Beta 1.0 e sua tag `v1.0.0` permanecem no histórico deste repositório.

## Compilar e publicar

Enviar alterações para `main` inicia o fluxo **Gerar APK**. Depois que a compilação passar, crie e envie a tag `v2.1.0-beta.1` para gerar a versão Beta 2.1:

```bash
git tag v2.1.0-beta.1
git push origin v2.1.0-beta.1
```
